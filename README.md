# gitglance

gitglance is a basic iOS app centered around a home screen widget that shows your GitHub contribution calendar for the last 3 months.

## Core features

- iOS home screen widget showing your last 3 months of GitHub contributions
- In-app goal setting for contribution targets
- Reminder support to help you stay consistent
- Streak tracking to build daily coding habits
- Multi-account support so you can follow both work and personal GitHub accounts
